# SKILL.md

## Purpose
WPWW WarRoom is a bounded local security/resilience laboratory and operator control plane.

## Skills demonstrated
- Security-system architecture
- Controlled attack/defence simulation
- Event/state modelling
- Audit trails and replay
- Docker-based lab orchestration
- CI/E2E verification
- Observability and bounded autonomy

## Safety boundary
All red-side experimentation is restricted to owned, local, scenario-driven targets. Generated attack material is simulation data and is not an authorization to target external systems.

## Evidence rule
Do not convert a passing container build into a claim of production security.
