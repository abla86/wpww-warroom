# Repository Change Audit — 2026-08-28

## Purpose
Material repository changes must be traceable to an approved scope, the exact Git diff, and verification evidence.

## Protected baseline
Existing content is not permission to change. Differences between working copies and GitHub do not authorise overwriting, deletion, relocation, refactoring, dependency changes, or documentation changes.

## Verification
Claims must match evidence. Historical authorisation is marked unknown when the originating request/work record is unavailable; it is never inferred from a commit title.

## Historical integrity
Git history is preserved. Corrections must use explicit corrective commits rather than rewriting history.
